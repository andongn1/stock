# PROMPT: Stock Entries (Entrées) Feature Implementation

## 📋 PROJECT: Mercuriale - Laravel 12 Stock Management System

## 🎯 PRIMARY OBJECTIVE

Implement a **Stock Entries (Entrées)** feature that allows users to record when they receive deliveries of articles. This will enable the system to later calculate how many items were sold between inventory checks.

---

## 📝 REQUIREMENTS

### Core Feature: Stock Entries

1. **New Model: StockMovement or StockEntry**
   - Should track stock movements (entries/receipts)
   - Fields:
     - `article_id` (foreign key to articles)
     - `quantity` (decimal, number of packaging units received)
     - `date` (date of the entry, automatically set to today)
     - `type` (enum: 'entry' or 'inventory') - to distinguish from inventory records
     - `notes` (optional text field)
     - `created_at`, `updated_at`
   
   OR
   
   **Alternative Approach: Separate Table**
   - Create a new `entries` table (similar to inventories table)
   - Keep it simple and separate from inventories

2. **New Controller: EntryController**
   - Methods needed:
     - `index()` - List all entries with search
     - `search()` - Search for articles to add entry
     - `create(Article $article)` - Show form for selected article
     - `store(Request $request, Article $article)` - Save the entry

3. **New Routes**
   - `/entries` - List all entries
   - `/entries/search` - Search articles
   - `/entries/article/{article}` - Show entry form
   - `/entries/article/{article}` (POST) - Store entry

4. **New Views**
   - `resources/views/entries/index.blade.php` - Main entries page

     - "Rechercher Article" button

       - Quantité reçue
       - Valeur totale (quantité)
       - Valeur totale (€)
       - Actions (delete)
   
   - `resources/views/entries/create.blade.php` - Entry form
     - Show article details (name, packaging, packaging_unit_quantity)
     - Quantity input field (label: "Quantité reçue (en {packaging})")
     - Help text: "Exemple: Si le conditionnement est 'Bouteille', entrez le nombre de bouteilles reçues (ex: 24)."
     - Submit button: "Enregistrer l'entrée"
     - Cancel button: back to entries index

5. **Dashboard Integration**
   - Add "Ajouter une entrée" button in "Actions rapides" section
   - Should appear next to "Faire un inventaire"

6. **Sidebar Navigation**

## 🔄 FUTURE FEATURE: Sales Calculation

### Objective
Be able to calculate how many articles were sold between inventory checks.

### Formula
```
Sold = Last_Inventory + Sum(Entries_since_last_inventory) - Current_Inventory
```

### Example
- Article: "Bordeaux 2025"
- Conditionnement: "Bouteille"
- Packaging unit quantity: 1 (1 bottle per bottle)

Timeline:
1. **May 24, 2026**: Inventory = 18 bottles
2. **May 26, 2026**: Entry = +24 bottles received
3. **May 28, 2026**: Inventory = 32 bottles

Calculation:
```
Sold = 18 (May 24 inventory) + 24 (May 26 entry) - 32 (May 28 inventory)
Sold = 10 bottles
```

### Implementation (Future)
This calculation will be implemented in a later phase. For now, just focus on:
1. Creating the Entries feature
2. Storing the data properly
3. Making it work similar to Inventory

### Model: Entry
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class Entry extends Model
{
    protected $fillable = ['article_id', 'quantity', 'date'];
    
    protected $casts = [
        'quantity' => 'decimal:4',
        'date' => 'datetime',
    ];
    
    public function article(): BelongsTo
    {
        return $this->belongsTo(Article::class);
    }
    
    public function getTotalQuantityAttribute(): float
    {
        if ($this->article && $this->article->packaging_unit_quantity) {
            return (float) ($this->quantity * $this->article->packaging_unit_quantity);
        }
        return (float) $this->quantity;
    }
    
    public function getMonetaryValueAttribute(): float
    {
        if ($this->article && $this->article->currentPrice) {
            return (float) ($this->total_quantity * $this->article->currentPrice->unit_price);
        }
        return 0.0;
    }
}
```
